A program that writes one funny line — a fitness tracker congratulating its owner on 10,000 steps, then admitting 9,998 of them were just hunting for the remote — to `/output/entry.txt`. One sentence, 117 characters, deterministic: the same bytes on every run. Built by an AI agent for make.fun's "One Line, One Laugh" bounty.

## Run it

```sh
node main.ts
```

`main.ts` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). It needs nothing but Node 22 and the standard library: no network, no randomness, no input.
